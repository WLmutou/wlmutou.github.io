nginx之configure

nginx
Linux/Unix
发布日期:   2018-05-23

configure 做检测操作系统内核和已安装的软件，参数解析,中间目录的生成以及
根据各种参数生成一些C源码文件、Makefile文件等。
查看configure如何工作，也可以看出Nginx的一些设计思想
以及，shell脚本这样写，清晰明了。

查看参数

./configure --help

help参数分为4大类型.

  1. 路径相关的参数
  2. 编译相关的参数
  3. 依赖软件的相关参数
  4. 模块相关的参数

默认参数在auto/options 里面有设定

详情

  1. 路径相关参数
    常用的参数设定
    –prefix=PATH nginx安装部署后的根目录(默认/usr/local/nginx)
    –conf-path=PATH nginx.conf的存放目录
    等等

  2. 编译相关的参数
    –with-cc=PATH C编译器的路径
    –with-cpp=PATH C预编译器的路径
    –with-cpu-opt=CPU 制定cpu架构

  3. 依赖软件的相关参数
    –with-openssl=DIR 指定OpenSSL库的源码位置
    –with-openssl-opt=OPTIONS 编译OpenSSL源码时希望加入的编译选项
    –with-zlib=DIR 指定zlib库的源码位置

  4. 模块相关
    1).事件模块,
    linux nginx 默认使用 epoll 事件模块
    2). 默认就会安装的HTTP模块(基本，不用管吧。就都安装上吧)
    3). 默认不编译进入Nginx的HTTP模块
    –with-http_ssl_module 安装http ssl module(依赖于OpenSSL)
    –with-http_realip_module 获取header信息X-Real-IP或X-Forwardef-For
    –with-http_addition_module 获取返回客户端的HTTP包体头部或尾部
    –with-http_xlst_module 依赖libxml2和libxslt，xml
    –with-http_secure_link_module 检查token参数是否属于特定用户发来或者时间戳是否过期

4).邮件代理mail相关
–with-mail 安装邮件服务器反向代理模块

  • configure 执行流
    configure 会调用 ./auto/目录下的脚本

产生目录objs

objs/
├── autoconf.err
├── Makefile
├── ngx_auto_config.h
├── ngx_auto_headers.h
├── ngx_modules.c
└── src
    ├── core
    ├── event
    │   └── modules
    ├── http
    │   └── modules
    │       └── perl
    ├── mail
    ├── misc
    └── os
        ├── unix
        └── win32

12 directories, 5 files

1)src目录用于存放编译时产生的目标文件。2)Makefile文件用于编译Nginx工程以及在加入install参数后安装Nginx。
3)autoconf.err保存configure执行过程中产生的结果。
4)ngx_auto_headers.h和ngx_auto_config.h保存了一些宏,这两个头文件会被src/core/ngx_config.h及src/os/unix/ngx_linux.h

ngx_modules.c文件就是用来定义ngx_modules数组的。
ngx_modules是非常关键的数组,它指明了每个模块在Nginx中的优先级,当一个请求同时符合多个模块的处理规则时因此,ngx_modules中模块的先后顺序非常重要,不正确的顺序会导致Nginx无法工作,这是auto/modules脚本执行后的
